Tilaus käsitellään maksun jälkeen. The order is processed after payment.

Node provisionoidaan ennen lähetystä. Tämä tarkoittaa, että tunnisteet ohjelmoidaan valmiiksi ennen toimitusta. The Node is provisioned before shipping. This means the tags are programmed before delivery.

Paketti sisältää kaksi ohjelmoitua tunnistetta: julkisen Node-tagin ja omistajan hallinta-avaimen. The package includes two programmed tags: a public Node tag and an owner control tag.

Julkinen tagi avaa objektin identiteetin. Omistajan hallinta-avain avaa hallinta- ja omistajapääsyn. The public tag opens the object identity. The owner control tag opens control and owner access.

Sovellusta tai kirjautumista ei tarvita. No app or login is needed.
