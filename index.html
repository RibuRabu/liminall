Mikä Node on What Node Is

Node on NFC-pohjainen fyysinen tunniste. Passiivinen artefakti — ei akkua, ei verkkoyhteyttä, ei prosessoria. Se kiinnitetään esineeseen, pintaan tai tilaan ja herää ainoastaan kun puhelin koskettaa sitä. Node is an NFC-based physical identifier. A passive artifact — no battery, no network, no processor. It attaches to an object, surface, or space and activates only when a phone comes close.

Kosketus avaa digitaalisen identiteetin. Omistaja määrittää, mitä avautuu. Identiteetti säilyy — se mitä se näyttää voi muuttua. Touch opens a digital identity. The owner defines what opens. The identity persists — what it shows can change.

Node ei sido esinettä yhteen viestiin tai yhteen käyttötarkoitukseen. Sama tunniste voi toimia tänään yhteystietosivuna, huomenna muistosivuna, ensi vuonna kokoelman osana. Node doesn't bind an object to one message or one use case. The same tag can work today as a contact page, tomorrow as a memorial, next year as part of a collection.

Fyysiset esineet kestävät yleensä kauemmin kuin niiden ympärille rakennetut digitaaliset kerrokset. Node on rakennettu samalle kestävyydelle. Physical objects usually outlast the digital layers built around them. Node is built for the same durability.

Käyttötapaukset Use cases

Node toimii kaikkialla, missä fyysisellä esineellä on merkitys, jonka haluaa tehdä jaettavaksi — henkilökohtaisessa elämässä ja liiketoiminnassa. Node works anywhere a physical object carries meaning worth sharing — in personal life and in business.

Memorial

Muistoesine, hauta, paikka, taideteos. Node tekee siitä kosketettavan muistamisen paikan, jota voi täydentää ajan myötä. A keepsake, grave, place, artwork. Node makes it a touchable place of remembrance that can grow over time.

Lost & Found

Avaimet, laukku, lemmikin kaulapanta. Node kertoo löytäjälle kenen se on ja miten palauttaa — ilman että yhteystiedot ovat julkisesti näkyvillä. Keys, luggage, a pet's collar. Node tells the finder whose it is and how to return it — without exposing your contact details publicly.

Collections

Taideteos, painos, harvinaisuus. Node liittää esineen provenienssiinsa, tarinaansa ja omistajuuteensa. An artwork, edition, rarity. Node connects an object to its provenance, story, and ownership chain.

Branded Objects

Tuote, pakkaus, rajoitettu erä. Node on brändin hallitsema fyysis-digitaalinen pinta, joka elää tuotteen koko elinkaaren ajan. A product, package, limited edition. Node is a brand-controlled physical-digital surface that lives through the entire product lifecycle.

Signage

Julkinen taulu, opaste, tila. Node tekee fyysisestä pinnasta päivitettävän digitaalisen kerroksen ilman vaihtotarvetta. A public board, sign, space. Node turns a physical surface into an updatable digital layer without replacement.
