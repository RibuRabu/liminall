Node Node

Liminall Node on fyysinen tunniste, joka avaa kohteelle määritetyn digitaalisen identiteetin puhelimen kosketuksella. Liminall Node is a physical identifier that opens a digital identity assigned to an object with a phone touch.

Sama tunniste pysyy paikallaan. Sisältöä voi päivittää myöhemmin omistajan hallinnassa. The same identifier stays in place. The content can be updated later under owner control.

Miten se toimii How It Works

Julkinen tunniste avaa objektin identiteetin. Hallinta-avain avaa omistajan pääsyn samaan Nodeen. The public identifier opens the object identity. The control key opens owner access to the same Node.

Omistajuus perustuu fyysiseen avaimeen, ei selainistuntoon. Ownership is based on a physical key, not a browser session.

Tekniset tiedot Technical Details

Liminall Node perustuu NFC-teknologiaan. Tunniste on passiivinen: siinä ei ole akkua eikä omaa verkkoyhteyttä. Liminall Node is based on NFC technology. The identifier is passive: it has no battery and no network connection of its own.

NFC toimii lyhyellä etäisyydellä, yleensä 1-4 cm. Puhelin lukee tunnisteen ja avaa omistajan määrittämän sivun. NFC works at a short range, usually 1-4 cm. The phone reads the identifier and opens the page defined by the owner.

Tunniste on yhteensopiva NFC-yhteensopivien puhelinten kanssa ilman erillistä sovellusta tai käyttäjätiliä. iPhone 7 ja uudemmat sekä useimmat Android-laitteet vuodesta 2016 eteenpäin tukevat lukemista suoraan käyttöjärjestelmätasolla. The identifier works with NFC-enabled phones without a separate app or account. iPhone 7 and newer, and most Android devices from 2016 onward support reading at the OS level.

Liminall Node käyttää NTAG213-siruteknologiaa tai suojattuja variantteja vaativampiin käyttökohteisiin. Alustoina voidaan käyttää polymeeriä, metallia tai komposiittia, myös metallipinnoille soveltuvina versioina. Liminall Node uses NTAG213 chip technology or protected variants for more demanding use cases. It can be produced on polymer, metal, or composite substrates, including versions for metal surfaces.

Julkinen tunniste ja hallinta-avain ovat erilliset. Muutoksia ei tehdä linkin kautta, vaan fyysisen avaimen kautta. The public identifier and the control key are separate. Changes are not made through a link, but through the physical key.
