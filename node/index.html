Node DIY Kit

Miten se toimii How it works
01

Saat kaksi ohjelmoitua NFC-tunnistetta: julkisen tagin ja omistajan hallinta-avaimen. You receive two programmed NFC tags: a public tag and an owner control key.

02

Kiinnität julkisen tagin esineeseen. Hallinta-avaimen pidät tallessa — se on ainoa pääsysi Noden identiteettiin. You attach the public tag to the object. You keep the control key safe — it's your only access to the Node's identity.

03

Kuka tahansa voi koskettaa julkista tagia NFC-yhteensopivalla puhelimella. Sivu avautuu. Ei sovellusta. Ei kirjautumista. Anyone can touch the public tag with an NFC-enabled phone. The page opens. No app. No login.

04

Päivität renderöinnin milloin tahansa hallinta-avaimen kautta. Identiteetti pysyy samana. Merkitys voi muuttua. You update the rendering at any time through the control key. The identity stays the same. The meaning can change.
