Mikä Node on What Node Is

Esine, jolla on ääni. Sisältö, joka kestää. Kosketus, joka yhdistää. An object with a voice. Content that lasts. A touch that connects.

Esine ja sen ääni An object and its voice

Fyysiset esineet kantavat merkityksiä, joita niiden omistajat eivät enää voi selittää. Vanha lahja, periytyvä työkalu, muistoesine — kaikissa on historia, jonka tietää vain se, joka oli siinä läsnä. Physical objects carry meanings their owners can no longer explain. An old gift, an inherited tool, a keepsake — each holds a history known only to those who were there.

Node ei luo tätä historiaa. Se antaa sille paikan, johon voi palata. Node doesn't create that history. It gives it a place to return to.

Miten tunniste toimii How the tag works

Node on litteä fyysinen tunniste. Ei akkua, ei verkkoyhteyttä. Se kiinnitetään esineeseen ja herää kun puhelin tulee lähelle — yleensä 1–4 cm etäisyydelle. Node is a flat physical tag. No battery, no network connection. It attaches to an object and activates when a phone comes within range — typically 1–4 cm.

Kosketus avaa omistajan määrittämän sivun. Alle sekunti. Ei sovellusta. Ei kirjautumista. iPhone 7 tai uudempi ja useimmat Android-laitteet vuodesta 2016 tukevat tätä suoraan käyttöjärjestelmätasolla. Touch opens the owner-defined page. Under a second. No app. No login. iPhone 7 and newer, and most Android devices from 2016, support this natively at the OS level.

Omistajuus ilman tiliä Ownership without an account

Jokainen Node DIY Kit sisältää kaksi NFC-tunnistetta. Julkinen tunniste kiinnitetään esineeseen — kuka tahansa voi koskettaa sitä. Hallinta-avain jää omistajalle. Se on ainoa tapa muokata Noden identiteettiä. Each Node DIY Kit contains two NFC tags. The public tag attaches to the object — anyone can touch it. The control key stays with the owner. It's the only way to edit the Node's identity.

Omistajuus perustuu fyysiseen avaimeen, ei selainistuntoon eikä salasanaan. Jos hallinta-avain katoaa, pääsy identiteettiin on poissa. Se on tarkoituksellista — juuri niin kuin fyysinen avain toimii. Ownership is based on a physical key, not a browser session or password. If the control key is lost, access to the identity is gone. This is intentional — exactly how a physical key works.

Mitä pysyy, mitä muuttuu What stays, what changes

Tunniste pysyy.
Sisältö muuttuu. The tag stays.
The content changes.

Node luodaan kerran ja se säilyy. Se mitä tunniste näyttää voi muuttua omistajan toimesta milloin tahansa. Node is created once and it persists. What the tag shows can be changed by the owner at any time.

Sama Node voi olla tänään yhteystietosivu, huomenna muistosivu ja ensi vuonna kadonneille tavaroille tarkoitettu palautussivu. Tämä erottaa Noden tavallisesta QR-koodista tai tavallisesta NFC-tagista. Node on tunniste, ei vain linkki. The same Node can be a contact page today, a memorial tomorrow, and a lost-item return page next year. This is what separates Node from an ordinary QR code or plain NFC tag. Node is an identity, not just a link.

Kenelle Node on Who Node is for

Henkilökohtaiseen käyttöön. For personal use.

Muistoesineet, lahjat, kokoelmat, kadonnut tavara — kaikkialla missä fyysinen esine kantaa merkitystä, jonka haluaa tehdä pysyväksi tai jaettavaksi. Node ei vaadi teknistä osaamista. Se vaatii vain jonkin, joka on tärkeä. Keepsakes, gifts, collections, lost belongings — anywhere a physical object carries meaning worth making persistent or shareable. Node requires no technical skill. It only requires something that matters.

Organisaatioille. For organizations.

Brändätyt tuotteet, pakkaukset, rajoitetut erät, museoesineet, julkinen opastus — Node on tunniste, joka elää tuotteen tai tilan koko elinkaaren ajan. Ilman infrastruktuuria. Ilman sovellusta. Ilman sitoutumista yhteen kampanjaan tai sisältöön. Branded products, packaging, limited editions, museum objects, public wayfinding — Node is a tag that lives through the entire lifecycle of a product or space. No infrastructure. No app. No commitment to a single campaign or piece of content.
